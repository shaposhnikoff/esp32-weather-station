# Application assets

`generated/landscape.c` contains original day/night RGB565 mountain and lake
illustrations generated by `tools/generate-landscape.c`. They are application
artwork created for this project; no reference-image pixels are used.
Both images together occupy 436,800 bytes of flash, with no decompression buffer.

Fonts use JetBrains Mono 2.304 Regular, licensed under SIL Open Font License 1.1.
The original font and license are retained in `fonts/`. Generated LVGL 8.4 fonts
include ASCII, Cyrillic, degree, minus, dash and ellipsis. The large numeric
font uses a reduced glyph set.

Regenerate all assets with `sh tools/generate-assets.sh` (Node/npm, a C compiler
and curl are required). The font converter is pinned to lv_font_conv 1.5.3.
Generated C files are source assets and should be retained with the project.
